# Design: kickoff 红黄绿灯自主推进改造

## 总体思路

skill 是协作协议的运行时投影。协议 v1.1 已有红黄绿灯 + 挂账不阻塞，本次只是把 kickoff/implement 两个 skill 里滞后的「一律等确认」gate 换成协议口径。**不发明新机制，只接线。**

改动全部是 Markdown 流程文本，两运行时（Claude SDK 加载 / Codex 直读）共用同一文件，改一处双生效。

## 关键设计决策

### D1: 红灯清单放 kickoff，implement 引用不复制
清单只维护一份（kickoff 新增「自主分级」章节），implement 在需要判灯的位置写「灯色判定见 kickoff 自主分级章节」。避免两份清单漂移。
Codex 直读场景下 implement 会引导再读 kickoff 对应章节，可接受（同目录文件）。

### D2: 分流点位置
- **轨道 A**：A2 汇报根因保留（大杰仍第一时间看到根因），但 A2 模板末行「等你确认根因后开始修复」改为分流结果措辞；A3 改名「灯色分流」——修复动作全绿/黄直接进 3.5.1→3.5.3→开 worktree 修，含红灯挂账。
- **残留清点**：实施时对两文件全文 grep「确认/获准/等待」逐条清点，已知残留：kickoff Step 3.5 前言「等 B6 获准实现 / 等用户在 A3 获准实施」、A2 模板末行。
- **轨道 B**：B5 汇报保留原格式但「下一步」措辞改为分流结果（"全绿黄，直接进入实现" / "含 N 个红灯项已挂账"），B6 触发条件从「用户确认后」改为「灯色分流通过后」。
- **汇报不省**：分流不取消汇报，大杰仍能在任何时点喊停；自主推进 ≠ 静默推进。

### D3: 挂账落点
红灯项三要素（背景+选项+我的建议）写驾驶舱「待大杰」栏 + 汇报「需要你决定」段。不新建挂账文件——协议里挂账账本在个人资产目录，驾驶舱已是任务级单一事实面板，够用。

### D4: 自 review 的 Codex fallback（一份规则，三处引用）
fallback 规则写在 kickoff 自主分级章节：无 Agent 工具时按该步骤原评审标准逐项自查输出结论，或调 codex review 插件。kickoff B3、implement Step 3b（审代码）、Step 4（审测试）三处引用，评审标准本身不变。

### D5: implement Step 5.5 改口
「用例表发给大杰→确认后执行」→「设计→自行执行→汇报三段式（思路/列表/逐条结果）」。Gate 从「大杰确认」改为「逐条执行通过 + 汇报含三段式」。含红灯动作的用例单独挂账。

### D6: 依赖链随挂
绿黄动作依赖红灯动作结果时（实现依赖挂账迁移、E2E 依赖挂账的合并部署），随红灯一起挂账并标依赖链，只推进可独立完成的部分。写进 kickoff 分级章节的挂账规则里。

### D7: ship 快速通道对齐
ship SKILL.md 的「高风险改动→分步走」判据改为显式引用红灯清单一句话，ship 不再是绕过红灯的旁路。ship 的 PR 合并等确认本来就保留，不动。

### D8: 明确不动的东西
- PR 合并 gate（Step 6/7）原样保留——共享分支合并是红灯固定项
- 开工三项确认保留——大杰唯一必看检查点
- 协作协议母版不动——skill 向协议对齐，不反向

## 测试计划

skill 是流程文档，无可执行代码，测试 = **场景推演验证**（拿改后文本走一遍典型任务，检查分流逻辑无歧义、无死路）+ 子 agent 评审。

**分层**：
- 纯文本推演（零 mock）：P0
- 子 agent 评审（Claude SDK 路径）：P0
- 真实任务试跑（下一个真任务时观察）：P1，本次不阻塞交付

**P0 用例（本次执行）**：
1. 纯绿黄功能任务推演：从"开搞"到 PR，全程无等待点（除 PR 合并）
2. 含红灯任务推演（含 DB 迁移的功能）：红灯挂账、其余完成、汇报含"需要你决定"
3. 轨道 A bug 推演（绿黄修复）：根因汇报后直接动手
4. 轨道 A 含红灯修复推演（修复需改生产配置）：根因照报，修复动作挂账
5. 拿不准场景推演：灯色模糊时文本明确指向升级
6. Codex 运行时推演：kickoff B3、implement Step 3b/4、E2E 步骤无 Agent 工具时均有明确 fallback 路径
7. E2E 用例含红灯动作推演（用例需向外部群发真实消息）：该用例挂账、其余执行
8. 直接触发 implement（不经 kickoff）推演：灯色规则经引用链可达、不断链
9. 回归推演：PR 合并仍等确认、开工三项仍输出、3.5 GitHub 绑定链路不受影响、ship 遇红灯挂账

**P1**：下一个真实任务按新流程跑，驾驶舱回看判级记录校准清单。

预估：9 个推演用例，覆盖 kickoff/implement/ship 三文件全部改动点。
