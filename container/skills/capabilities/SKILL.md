# 实例能力

只读检查当前运行环境，不根据固定挂载路径判断用户能否使用本命令。

- 先核对当前工作目录和运行时提供的技能目录；从SKILL.md元数据读取名称与描述。区分已暴露入口、磁盘安装和未加载插件；目录名不一定等于命令名。
- 工具以本会话实际暴露的清单为准；需要时使用工具发现能力。缺少工具就如实说明，不套用其他运行时的固定工具表。
- 用户询问CLI时，用command -v定位，再用对应--help或--version核对。不安装依赖，不登录，不运行有副作用的业务命令。
- 群身份、可访问目录与权限以当前配置或工具返回为准；不能从路径存在推断管理员身份。
- 只读用户问题所需的元数据；不读取、打印凭据或无关群的私有文件。

简要报告已确认能力及不可验证项，用户要求完整清单时再展开。健康检查转 [status](../status/SKILL.md)。
