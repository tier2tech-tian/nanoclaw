# 连续交付

串联现有流程，不维护第二套实现步骤：

1. 用 [kickoff](../kickoff/SKILL.md) 对齐需求、验收标准、驾驶舱和项目跟踪；已完成的启动工作直接复用。
2. 执行 [mp-implement](../mp-implement/SKILL.md)，增量实现、测试、独立审查并按项目规则提交PR。
3. 改动涉及用户可见流程时执行 [e2e-testing](../e2e-testing/SKILL.md)，保存真实验证证据。
4. 汇报实现、验证、PR及部署状态；需要用户决定的事项集中列出。用户要求收尾时执行 [wrapup](../wrapup/SKILL.md)。

已获授权的普通步骤连续推进，不重复询问。数据迁移、生产或共享环境写入、花钱、对外发布、合并及重启仍遵守各自授权；挂起未授权步骤和依赖它的工作，其他部分继续。

测试失败先调查并修复，不用固定重试次数替代诊断。环境不可用、审查能力缺失或真实链路未验收时明确记录，不能称为完整交付通过。
