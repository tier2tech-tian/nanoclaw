# 95分 造数 skill（fen95-datafactory 0.4.0）能力清单

> 给同事看的版本。一句话：**把"用例需要什么数据/状态"变成 T1 里一张真实可点的单或一件商品**。环境只支持 T1。
> 数据来源：配方表 89 条（飞书 Base tblrZVesFOvjpDpM）+ 状态机 63 状态 59 边。2026-10-14 导出。

## 一、怎么用

- **数字员工**：需求测试员工已接入，派活时自动带上；员工按 CLAUDE.md 在需要前置数据时自己调用。
- **人**：细狗 xigou 上 `~/ai/nine-refine/nanoclaw/container/skills/fen95-datafactory/`，或任何能访问办公网的机器。五步：
  1. 把用例翻成目标状态：`smq.py search <关键词>`
  2. 问状态机怎么到：`smq.py how <seller|recycle|buyer> <状态码> [类目] [类型] --json`
  3. 查配方拿命令：`rq.py <配方id>` / `rq.py find <关键词>`
  4. 调造数工厂：`df.py supply|trade <接口> '<JSON>'`，**账号 = 请求里的 mobile，要用哪个 T1 测试号就传哪个**
  5. 核终态：`t1q.py seller|recycle|buyer <单号或 goods_id>`，再在 App 深链看一眼
- 验证程度三档：**已验证**（真跑过、库里核过）/ **已填未验**（有路径没跑通）/ **待填**（只知道要什么，没方案）。用的时候先看档。

### 6. 账号状态（14 条）/ 地址资料（3 条）/ 活动运营位（3 条）

- **已验证**：新人态、已开店、有余额、有关注/有我有、有未读消息、未登录、首次安装、"我有"可卖了换钱、多地址、有收货地址、未实名、商品有券。
- **已填未验**：已绑定尺码、AB 新版出售页、外部来源跳入。
- **待填**：我有已勾选、新用户首单。
- **等窗口/不可造**：秒杀、费率活动、首页运营位（档期型）。

## 三、明确不能的

- 预发 / 线上一律不造；退登、删数据、实名、删除类按钮不碰。
- 回收单、拍卖线没有"真实感商品"；服务包线只透传图/价未单独验。
- 同运单批量建单两单会共用一件池商品。
- 非鞋类目的瑕疵在 T1 是借节点写真实文案，瑕疵 id 和线上不对应。
- 状态机里标"推断"的边不要当事实。
